## cdd コマンド
git clone XXX やmkdir XXXを行ったあと，そのXXXディレクトリに入るためのcdコマンド.
### 使い方
git clone XXXXX
cdd 
clone後にcd でXXXXXに入るのと同じ．

mkdir XXX
cdd
XXXディレクトリ作成後にcd でXXXに入るのと同じ



## pwdd　コマンド
２番目に入力した文字列が含まれるファイルまたはフォルダのフルパスを表示

### 使い方（User)
pwdd ex
/current path/example.txt
/current path/example

が表示される



### 使い方（Dev）
`git clone https://github.com/kanaji2002/shortcut-command.git `

`cd shortcut-command`

`source .bashrc`
